# GitHub Pages setup

1. Open **Settings → Pages**.
2. Select **Deploy from a branch** using `main` and `/ (root)`.
3. Keep the custom domain set to `magicfox.space`.
4. Create apex `A` records for `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, and `185.199.111.153`.
5. Create `www` as a `CNAME` pointing to `karoda1995.github.io`.
6. Enable **Enforce HTTPS** after the certificate becomes available.
